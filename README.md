# AirUnit — каталог товарних даних

Публічний репозиторій підготовлених товарних даних AirUnit у форматі JSON для інформаційних сервісів компанії. Дані оновлюються автоматично на основі товарного каталогу AirUnit.

## Опубліковані файли

| Файл | Опис |
| --- | --- |
| [`latest/products.json`](latest/products.json) | Перелік товарів та доступні товарні атрибути |
| [`latest/categories.json`](latest/categories.json) | Структура категорій |
| [`latest/search-index.json`](latest/search-index.json) | Дані для пошуку товарів |
| [`latest/manifest.json`](latest/manifest.json) | Дата формування, версія формату та кількість записів |

Для перевірки актуальності відкрийте `latest/manifest.json` і перегляньте поле `generated_at` (час UTC). Значення `counts` описує кількість записів у відповідних файлах.

Дані є автоматично сформованим знімком і не обов'язково охоплюють увесь асортимент магазину. Наявність товару у файлі **не гарантує** його поточну доступність, незмінність ціни чи умов продажу.

## Умови використання

Репозиторій призначений для публікації даних, а не для редагування товарів вручну. Зміни до `latest/*.json` можуть бути перезаписані під час наступного автоматичного оновлення.

Відомості, що потребують підтвердження (ціна, наявність, характеристики), слід перевіряти за актуальними даними компанії. Публікація JSON не означає надання окремої ліцензії на стороннє комерційне використання даних, зображень або описів.

## Безпека

У репозиторії не повинно бути облікових даних, API-токенів, приватних журналів, конфігурацій авторизації або внутрішніх документів. Якщо ви виявили потенційно чутливі відомості, повідомте компанію через її офіційні канали зв'язку, не створюючи публічну issue з такими відомостями.
